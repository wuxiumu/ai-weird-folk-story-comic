# AI 怪谈民谣漫画 · ai-weird-folk-story-comic

> 计划做成 **AI 辅助的怪谈 / 民谣风竖版漫画流水线**（分镜 → 画面 → 文案 → 导出），面向短视频与图文平台。  
> **现状：上游空仓**——本仓先钉死定位与 MVP 路线图，不假装成品。

**定制：** 微信 **qingbao199101**（备注：怪谈漫画）｜ [wuxiumu@163.com](mailto:wuxiumu@163.com)

## 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| AI 怪谈/民谣题材漫画内容生产线方案 | 已上架可商用的完整漫画 App |
| 分镜脚本 + 出图 + 字幕/旁白可定制流水线 | 自动爬取他人版权内容的工具 |
| 可按系列/人设交付的起点 | 现成 SaaS 漫画站托管 |

## MVP 路线图

1. **M1**：故事大纲模板 + 分镜 Markdown 约定 + 样例 1 话静态页  
2. **M2**：文生图/图生图提示词库（怪谈/民谣风格）+ 批量出图脚本骨架  
3. **M3**：竖版漫画阅读页（Web）+ 导出短视频字幕轨  
4. **M4**：系列管理后台最小版 + 白标皮肤  

详见 `docs/ROADMAP.md`。
